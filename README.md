# System

A personal leveling app for Windows in the style of the system windows from the anime Solo Leveling.
Daily quests, stats, levels, penalties and system calls that pop up while you work.

**[Download System-Setup.exe](https://github.com/EzDavidos/system-app/releases/latest/download/System-Setup.exe)**

## Install

1. Download `System-Setup.exe` from the link above.
2. Run it. Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
   The app is free and not signed with a paid certificate, that is why Windows warns.
3. The app installs for your user only, no admin rights needed, and opens right away.

After that it starts with Windows and waits in the tray. Updates download by themselves.

Your progress is stored on your computer in `%APPDATA%\solo-leveling`. Uninstalling the app keeps it.

# System (RU)

Приложение для прокачки себя на Windows в стиле системных окон из аниме Solo Leveling.
Ежедневные задания, статы, уровни, штрафы и системные вызовы, которые всплывают во время работы.

**[Скачать System-Setup.exe](https://github.com/EzDavidos/system-app/releases/latest/download/System-Setup.exe)**

## Установка

1. Скачай `System-Setup.exe` по ссылке выше.
2. Запусти. Windows может показать «Система Windows защитила ваш компьютер»: нажми **Подробнее**,
   затем **Выполнить в любом случае**. Приложение бесплатное и не подписано платным сертификатом,
   поэтому Windows предупреждает.
3. Установка только для твоего пользователя, без прав администратора, приложение сразу откроется.

Дальше оно запускается вместе с Windows и ждёт в трее. Обновления скачиваются сами.

Прогресс хранится на твоём компьютере в `%APPDATA%\solo-leveling`. При удалении программы он остаётся.
